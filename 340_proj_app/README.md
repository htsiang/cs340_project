# Shining Pearl Spa Database 
This work represents the culmination of 11 weeks of collaboration by Group 88: Josephine Lyou and Hsin-May Tsiang. Our aim was to make data organization for a Pokemon Spa more accessible and easier to maintain, intended as a replacement to an old system made up of multiple Microsoft Excel spreadsheets.

This database project showcases database design, SQL, and web application development. 

**Link to project: http://classwork.engr.oregonstate.edu:13138** 

## How It Was Made:

**Technology:** HTML, CSS, JavaScript, SQL, React, Express, Node.js

This database was created using MySQL. ER Diagrams and schemas were created using MySQL workbench. 

**Database structure**
Contains 4 tables and 1 intersect table:
* Trainers
* Pokemon
* Treatments
* Sessions
* SessionsHasTreatments - an intersect table
